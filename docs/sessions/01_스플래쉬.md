## 이 세션의 담당 영역: 스플래쉬 스크린

### 관련 파일
| 파일 | 역할 |
|------|------|
| `src/components/SplashScreen.tsx` | 스플래쉬 UI 컴포넌트 |
| `src/App.tsx` | 스플래쉬 제어 로직 |

### 현재 구현 상태
- `sessionStorage.getItem('moto_splash') === '1'` 이면 스킵 (세션당 1회만 표시)
- `SplashScreen` 컴포넌트가 `onComplete` 콜백으로 완료 신호 전달
- `App.tsx`에서 `splashDone` 상태로 제어:
  ```tsx
  const [splashDone, setSplashDone] = useState(() =>
    sessionStorage.getItem('moto_splash') === '1'
  )
  if (!splashDone) return <SplashScreen onComplete={handleSplashComplete} />
  ```

### App.tsx 스플래쉬 관련 코드
```tsx
const handleSplashComplete = () => {
  sessionStorage.setItem('moto_splash', '1')
  setSplashDone(true)
}
```
