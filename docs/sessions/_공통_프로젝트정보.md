## 앱 구조
```
src/
├── App.tsx                    # 라우터 루트, Provider 구성
├── main.tsx
├── pages/
│   └── LandingPage.tsx        # 로그인 전 랜딩
├── components/
│   ├── SplashScreen.tsx       # 스플래쉬 (세션당 1회)
│   ├── Layout.tsx             # 탭바 + DriveSessionOverlay
│   ├── AuthModal.tsx          # 로그인 모달
│   ├── DriveSessionOverlay.tsx # 주행세션 전역 UI
│   └── NavigationCountdownPopup.tsx
├── features/
│   ├── record/                # 기록 탭
│   ├── tour/                  # 코스 탭
│   ├── my-routes/             # 내 경로 탭
│   ├── garage/                # 차고 탭
│   └── profile/               # 프로필 탭
├── context/
│   ├── RideRecordContext.tsx  # GPS 기록 전역 상태
│   ├── ThemeContext.tsx       # 다크/라이트 모드
│   └── FuelContext.tsx        # 연료 기록 상태
└── lib/
    ├── supabaseClient.ts
    ├── courseStorage.ts       # 로컬 코스 저장
    ├── courseService.ts       # Supabase 코스 동기화
    ├── driveSession.ts        # 주행세션 localStorage
    ├── naviUtils.ts           # 내비 딥링크/SDK
    └── profileService.ts
```

## 라우팅 구조
```
/              → LandingPage (로그인 전)
/map           → MapPage (기록 탭)
/courses       → TourPage (코스 탭)
/my-routes     → MyRoutesPage (내 경로 탭)
/garage        → GaragePage (차고 탭)
/profile       → ProfilePage (프로필 탭)
/settings      → SettingsPage
/route-planner → RoutePlanner
```

## Provider 계층 (App.tsx)
```
ThemeProvider
  FuelProvider
    RideRecordProvider    ← GPS 기록 전역
      BrowserRouter
        AuthListener
        Routes (Layout 포함)
          DriveSessionOverlay  ← Layout 내부
```

## 주의사항
- **빌드 먼저**: 수정 후 반드시 `npm run build` 성공 확인 후 push
- **카카오 좌표**: `x = 경도(lng)`, `y = 위도(lat)` — Places API 결과 형식
- **Tailwind 커스텀값**: `bg-white/8`, `bg-white/6` 등 슬래시 표기 사용 중
- **async useEffect**: useEffect 콜백은 async 불가 → 내부 async 함수로 분리
