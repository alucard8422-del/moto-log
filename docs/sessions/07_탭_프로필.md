### 현재 구현 상태

#### 프로필 페이지
- 유저 정보 표시 (닉네임, 프로필 이미지)
- 주행 통계 요약 (총 거리, 횟수 등)
- 배지 시스템 (`BadgeGrid`)
- 저장된 코스 탭 (`SavedTab`)
- 내비 설정 (`NaviSettingsCard`)

#### 배지 시스템
```ts
// src/constants/BadgesData.ts
export const BADGES = [...]        // 배지 목록
export type Tier = 'bronze' | 'silver' | 'gold' | 'platinum'
export const RIDE_DIARY_TIER_META  // 주행 일기 배지 티어별 메타
```
- 배지 획득 시 `BadgeAchievementModal` 표시
- `checkRideDiaryBadge()`: 주행 일기 작성 배지 체크

#### 내비 설정 (NaviSettingsCard)
- T맵 / 카카오맵 / 아틀란 선택
- `localStorage: 'moto_navi_pref'`로 저장
- `loadNaviPref()` 함수로 불러오기

#### 설정 페이지 (SettingsPage)
- 다크/라이트 모드 전환 (ThemeContext)
- 계정 설정, 로그아웃

#### ThemeContext
```ts
// CSS 변수로 테마 적용
--bg-surface, --text-main, --text-muted, --brand, --border, --glass-bg 등
```
