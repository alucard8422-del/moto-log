### 현재 구현 상태

#### 코스 탭 주요 기능
- 추천 코스 목록 표시 (커뮤니티 공유 코스)
- 코스 카드 탭 → 상세 모달 (`CourseDetailModal`)
- 카카오 로드뷰 연동 (`RoadviewModal`)
- 코스 공유 기능 (커뮤니티에 공유)

#### 데이터 구조 (SavedCourse)
```ts
interface SavedCourse {
  id:              string
  title:           string
  distanceKm:      number
  durationMin:     number
  gpxPoints:       GpxPoint[]
  gpxXml?:         string
  createdAt:       string
  isShared:        boolean
  communityShared?: boolean
  diary?:          string       // 메모
  coverPhoto?:     string       // 커버 사진 URL
  plannerWaypoints?: NaviWaypoint[]  // 계획 경유지
  startCity?:      string
  endCity?:        string
}
```

#### 카카오맵 연동
- 로드뷰: `window.kakao.maps.Roadview`
- Geocoder: `window.kakao.maps.services.Geocoder`
- SDK URL: `dapi.kakao.com/v2/maps/sdk.js?appkey=d2430786a3a92cc28ebf4f0a22993062&libraries=services`
