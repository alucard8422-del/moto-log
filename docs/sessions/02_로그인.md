## 이 세션의 담당 영역: 로그인 / 인증

### 관련 파일
| 파일 | 역할 |
|------|------|
| `src/pages/LandingPage.tsx` | 비로그인 시 초기 랜딩 화면 |
| `src/components/AuthModal.tsx` | 로그인 모달 (이메일/소셜) |
| `src/components/AuthListener.tsx` | Supabase 인증 상태 전역 감지 |
| `src/lib/supabaseClient.ts` | Supabase 클라이언트 초기화 |
| `src/lib/profileService.ts` | 유저 프로필 조회/저장 |

### 인증 시스템 현황
- **Supabase Auth** 사용
- 이메일/패스워드 로그인 구현됨
- **카카오 로그인**: 아직 미구현 (예정)
- `AuthListener.tsx`: `supabase.auth.onAuthStateChange` 감지 → 전역 상태 반영

### 라우팅 흐름
```
앱 시작
  ↓ (스플래쉬 완료)
  ↓ splashDone = true
App.tsx → BrowserRouter
  └─ / → LandingPage (로그인 유도)
  └─ /map, /my-routes 등 → 로그인 필요 페이지
```

### LandingPage 현재 상태
- 로그인 안 된 사용자에게 보여주는 랜딩
- "시작하기" 버튼 → `AuthModal` 열림

### AuthModal 현재 상태
- 이메일 + 패스워드 로그인/회원가입
- Supabase `signInWithPassword`, `signUp` 사용
- 카카오 로그인 버튼 UI 있으나 실제 연동 미완성
