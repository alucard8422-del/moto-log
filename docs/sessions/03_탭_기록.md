### 현재 구현 상태

#### GPS 기록 (RideRecordContext)
- `startRecording()`: GPS watchPosition 시작, Wake Lock 획득
- `stopRecording()`: GPS 종료, 코스 로컬 저장 + Supabase 동기화, `status = 'finished'`
- `resumeFromCheckpoint()`: 앱 재시작 후 저장된 체크포인트에서 이어달리기
- 30초마다 체크포인트 자동 저장 (`localStorage: 'moto:ride_checkpoint'`)
- `status`: `'idle' | 'riding' | 'finished'`

#### UI 흐름
```
idle 상태
  ↓ ▲ 삼각형 버튼 탭
  팬 메뉴 열림 [바로 시작 | 내비로 시작 | 내비 선택]
  
"내비로 시작" → 드라이브세션 체크 → (근처면) "이어달리기?" 팝업
"바로 시작"  → startRecording() 즉시
"내비 선택"  → NaviSettings 시트

riding 상태
  → ●REC 배지 + 빨간 정지 버튼
  → 정지 버튼 탭 → "기록 중지?" 확인 → stopRecording()

finished 상태
  → "Ride Complete" 시트 (거리, 시간, 평균속도)
  → "내 경로에 저장하기" 버튼 → /my-routes 이동
```

#### 드라이브세션 이어달리기 (MapPage.handleStart)
- "내비로 시작" 누를 때 `loadDriveSession()` 확인
- 드라이브세션 있으면 GPS 위치 체크 (스피너 표시)
- 30km 이내: "설정한 경유지에 도착하지 않았습니다. 이어달리겠습니까?" 팝업
  - [이어 달리기]: `startRecording()` + `moto:startDrive` 이벤트 dispatch
  - [취소하기]: idle 유지
- 30km 초과: 드라이브세션 초기화 후 일반 카운트다운

#### DriveSessionOverlay (계획 경로 구간 안내)
**기록 중일 때만 작동** (`recordStatus === 'riding'`)

상태 머신:
```
countdown → (내비 실행) → naviActive → (GPS 도달 확인) →
  ├─ nextSegment: "다음 경유지로 안내할까요?" [안내하기][취소하기]
  │    └─ 취소하기 → stopConfirm: "기록 중지" [중지][취소]
  └─ notArrived: GPS 미도달 [종료|구간완료|계속주행]
```

#### 내비 연동
- **T맵**: `tmap://route?...` 딥링크, 경유지 최대 5개
- **카카오**: `Kakao.Navi.start()` JS SDK (경유지 최대 3개), 실패 시 `kakaomap://` 폴백
- **아틀란**: `atlan://` (기본)
- 구간 분할: `splitIntoSegments()` — 겹침 없이 분할 (1-5번, 6-10번 등)

#### 카카오맵 표시 (MapDisplay)
- `dapi.kakao.com/v2/maps/sdk.js` 동적 로드
- GPS 경로 선 표시, 현재 위치 마커
